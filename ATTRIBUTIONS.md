# Media and attribution

The repository should contain original demos or assets with redistribution permission.

For every third-party asset, record:

- creator or source
- original URL
- license or written permission
- download date
- the exact file used

Do not add downloaded social-media videos without permission. Links to trend references may be documented in prose, but the media itself should remain on the original platform.
